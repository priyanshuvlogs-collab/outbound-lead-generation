# outbound-lead-generation

Repeatable outbound motion for a done-for-you pipeline service targeting freshly funded, pre-seed–Series A B2B software companies. Built 2026-08-19 from public sources only; every trigger has a URL, every unknown is marked UNVERIFIED, nothing is invented.

## Before anything sends

1. Fill the UNVERIFIED fields in the offer snapshot (sender, mailbox, booking link).
2. Connect an email verifier (Hunter / Apollo / Truelist) — **every email in the sheet is currently `unverified` and may not enter a sequencer**.
3. Verify the 11 priority contacts; verified rows are promoted from Warm to Hot.
4. Load verified contacts into Instantly / Smartlead / Lemlist. Send caps and rules are in `ops/weekly-cadence.md`.
5. Every Friday, bring the metrics back with `why no replies` if under the healthy band.
